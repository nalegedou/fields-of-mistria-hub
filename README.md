# Fields of Mistria Hub 🌾

The complete wiki & guide for **Fields of Mistria** — the cozy farming RPG by No Sun Studios.

## Project Structure

```
site/
├── index.html              # Homepage (10 page cards, stats, quick links)
├── css/style.css           # Main stylesheet (game-wiki theme)
├── js/main.js              # Navigation toggle, search, interactions
├── guide/index.html        # Complete Beginner Guide
├── crops/index.html        # Crops List & Farming (60+ crops data tables)
├── fishing/index.html      # Fishing Guide (locations, legendary fish)
├── mining/index.html       # Mining & Combat (5 biomes, seals, tips)
├── cooking-recipes/index.html  # Cooking Recipes (100+ dishes)
├── romance/index.html      # Romance & Dating (12 candidates)
├── gift-guide/index.html   # Gift Guide (all NPC preferences)
├── skills-perks/index.html # Skills & Perks (9 skill trees)
├── characters/index.html   # Characters & Quests (22 NPCs)
└── codes-updates/index.html# Updates & Patch Notes (v1.0+ history)
```

## Features

- ✅ **10 content pages** covering all major game systems
- ✅ **SEO-optimized**: Title/Description meta tags, canonical URLs, Open Graph tags
- ✅ **Responsive design**: Mobile-friendly with collapsible nav
- ✅ **Data tables**: Crops, fish, recipes, perks — all in searchable tables
- ✅ **Internal linking**: Related guides cross-linked on every page
- ✅ **Sticky header navigation** with search
- ✅ **Breadcrumb navigation** on all inner pages
- ✅ **Sidebar TOC** (Table of Contents) on article pages
- ✅ **Clean game-wiki aesthetic** matching Mistria's cozy farm vibe

## How to Run Locally

```bash
# Option 1: Python (any version)
cd site
python -m http.server 8080
# Open http://localhost:8080

# Option 2: Node.js
npx serve site
# Or: npx http-server site -p 8080
```

## Tech Stack

- Pure static HTML/CSS/JS (no framework dependencies)
- Semantic HTML5 for SEO
- CSS Custom Properties for theming
- Vanilla JS for interactivity (~60 lines)
