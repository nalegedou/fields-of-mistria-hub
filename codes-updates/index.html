📋 Updates & Patch Notes

Full version history from Early Access to v1.0+, new feature changelogs, and the truth about cheat codes.

Cheat Codes: The Truth ⚠️

⚠️ Important: Fields of Mistria does NOT have built-in cheat codes or console commands. Unlike Stardew Valley, there is no item-spawning console. If you want to use cheats, you'll need third-party tools like trainers (PC only) — but be aware these can corrupt your save file.

Version History

v1.0.4 — Latest (August 2025)

  • Bug Fixes: Fixed crash when entering Greenhouse with certain crop configurations.
  • Stability: Improved memory usage on Switch and lower-end PCs.
  • Balancing: Slightly increased Starfruit growth time (20→22 days) for better game balance.

v1.0.3 (July 2025)

  • Performance: Major optimization pass — load times reduced by ~40% on HDD systems.
  • Quality of Life: Added "Sort by Category" to inventory screen.
  • Bug Fixes: Fixed marriage cutscene not triggering for some players at 10 hearts.

v1.0.2 — Marriage & Children Update (June 2025) 🎉

  • NEW: Full marriage system — propose with Mermaid's Pendant after 10 hearts + Bouquet.
  • NEW: Children system — max 2 kids per marriage, baby arrives 14 days after decision.
  • NEW: Spouse farm help — configure watering/animal care automation.
  • NEW: Wedding ceremony event — 3-day countdown with town-wide celebration.
  • New Items: Bouquet (from shop), Mermaid's Pendant (from old mariner).

v1.0.1 (May 2025)

  • Hotfixes: Resolved save corruption issue affecting a small % of players.
  • Bug Fixes: Fixed quest "The Lost Relic" not completing properly.
  • Localization: Updated German and French translations.

v1.0.0 — Official Launch! 🚀 (April 2025)

  • Left Early Access! Full 1.0 release after 18 months in EA.
  • NEW: Final story arc — confront the source of the magical earthquakes.
  • NEW: 4 new NPCs including hidden romanceable characters.
  • NEW: Ancient Ruins mine biome (Floors 101–120+).
  • NEW: 15 new Steam achievements (total now 69).
  • Price Change: $19.99 (EA was $14.99).

v0.9.x — Late Early Access (Jan–Mar 2025)

  • v0.9.5: Added Pet system (cat/dog choice), Apiary building, Terrariums.
  • v0.9.3: New mine biome (Lava Caves, Floors 71–100), Fire Seal unlock.
  • v0.9.0: Major skill tree overhaul — perks rebalanced across all 9 skills.

v0.8.x – v0.5.x — Mid Early Access (2024)

  • v0.8.0: Cooking system overhaul — 60+ new recipes added.
  • v0.7.0: Romance system introduced (12 candidates, heart events).
  • v0.6.0: Town Repair system expanded — Community Center bundles.
  • v0.5.0: Fishing rework — new fish species, tackle system, legendary fish.

v0.12.1 – v0.4.x — Early Early Access (2023–Late 2024)

  • Initial release had basic farming, mining, fishing, and 6 NPCs.
  • Each update added crops, fish, mine floors, and NPC dialogue.
  • Save compatibility maintained throughout EA (rare for indie games!).
